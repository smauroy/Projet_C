Equipe : Séverine et Huy

Projet : Traducteur Vietnamien ← → Français

Description :

Réaliser un éditeur graphique sur lequel on peut écrire et faire traduire une phrase.
Vietnamien
   ↓↑
Français

Objectifs/Conditions de réalisation : 

- Création d'un fichier Makefile
- Definition de l'alphabet
- Utilisation d'API de dictionnaire pour la traduction
- Enregistrement/Récupération des informations
- Extraction des échanges avec choix de format
- 2 interfaces graphiques : Séverine sous SDL et Huy sous GTK 4 (2 compiles différentes via make)
